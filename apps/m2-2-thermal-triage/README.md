# M2.2 Thermal Triage: Case File

A self-contained, desktop-first case review activity. Four observations pair original synthetic thermal and visual SVG views. Learners mark the relevant area, classify evidence, attach a validation action, and then prioritise the finding with the strongest support for further energy-performance investigation.

The 100-point score allocates 20 points to each observation (focus 4, classification 8, validation 8) and 20 to the final decision (finding 10, reason 10). A correct decision on its first submission receives full points, after one incorrect submission half points, and after further errors zero. Every critical interpretation must be corrected before moving on. Passing requires at least 75 points. The shared SCORM wrapper reports the best completed passing result on replay.

`locales/en.json` contains all normal learner-facing text. The four thermal and four visual SVGs in `public/assets/` were authored for this game. They are illustrative, use no real temperatures, and include no third-party media. The application has no runtime network dependency.

From this folder, run `npm run test`, `npm run dev`, or `npm run build` after installing the repository's root dependencies. The root QA and SCORM packaging commands also include this game.
